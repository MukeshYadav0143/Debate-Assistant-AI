\# Debate Assistant AI



An AI-powered debate platform that helps users practice debates, generate arguments, challenge an AI opponent, and improve their debating skills.





\## 📊 Dashboard



!\[Dashboard](screenshots/dashboard.png)



\## 🚀 Features



\- 🤖 AI Argument Generator

\- 🗣️ AI Debate Opponent

\- 📊 Debate Skill Analysis

\- 📚 Debate History

\- 💡 AI Topic Generator

\- 📈 Dashboard with skill scores

\- 🧠 Local AI using Llama 3.2

\- 💾 MongoDB database



\## 🛠️ Tech Stack



\### Frontend

\- React.js

\- Vite

\- Tailwind CSS



\### Backend

\- Python

\- FastAPI

\- REST API



\### AI

\- Ollama

\- Llama 3.2



\### Database

\- MongoDB
